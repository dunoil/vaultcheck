Counting rules

This dashboard counts only what the activity log records, and the log was seeded only from STATUS.md and flow-run-final.log:

  1. A check counts only when a check_passed event with its full answer payload is in the log. So far that is the final run of 25 Nov 2026.
  2. Credits count only from agent_funded and agent_topup events that carry a ledger sequence.
  3. Top ups at ledger seq 24802 and 24808 show further check activity in earlier runs, but without recorded answer payloads those checks are not counted.
  4. If a metric cannot be grounded in a record, it is left out rather than estimated.
